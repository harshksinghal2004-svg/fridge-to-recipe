# FridgeChef — Frontend Client

React 19 single-page application built with Vite for the FridgeChef AI-powered recipe generator.

## Features
- **Modern Glassmorphic Dark UI**: Custom CSS design system with fluid animations and responsive layout.
- **Dynamic Serving Scaling**: Interactive multiplier for ingredient measurements.
- **Interactive Checklist**: Real-time progress tracking for recipe instructions.
- **Smart Swaps**: Contextual ingredient alternatives.
- **Robust API Client**: Concurrent request cancellation using `AbortController`.

## Scripts
- `npm run dev` - Start local Vite development server
- `npm run build` - Build production bundle to `dist/`
- `npm run preview` - Preview production build locally
